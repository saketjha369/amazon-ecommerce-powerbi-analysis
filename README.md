# Amazon E-Commerce Performance Analysis

An end-to-end e-commerce data analysis project using **Power BI, DAX, Power Query, SQL, and Excel** to analyze sales performance, customers, products, returns, delivery, and geographical trends.

---

## 📌 Project Overview

This project analyzes Amazon e-commerce data to understand business performance and generate data-driven insights.

The analysis focuses on:

- Sales and revenue performance
- Customer behavior and purchasing patterns
- Product and category performance
- Returns and customer satisfaction
- Delivery performance
- Geographical sales distribution
- Year-over-year and monthly sales trends

---

## 🎯 Objectives

- Analyze overall sales and revenue performance.
- Identify high-performing products and product categories.
- Understand customer purchasing behavior and customer value.
- Analyze returns, ratings, and delivery performance.
- Identify geographical sales patterns and business opportunities.
- Build an interactive Power BI dashboard for business analysis.
- Perform advanced SQL analysis using aggregations, CTEs, subqueries, and window functions.

## 🧮 SQL Analysis

The project includes advanced SQL analysis using:

- `GROUP BY`
- `HAVING`
- Aggregate Functions
- CTEs
- Subqueries
- `CASE`
- `LAG()`
- Window Functions
- Date-based analysis
- Revenue calculations

### SQL Questions Covered

1. Top 5 most valuable customers using a composite score.
2. Month-over-month revenue growth.
3. Rolling 3-month average revenue by product category.
4. 15% discount for customers with at least 10 orders.
5. Average days between consecutive customer orders.
6. Customers whose revenue is more than 30% above average.
7. Top 3 product categories based on year-over-year sales growth.

The complete SQL queries are available in:

`SQL/amazon-ecommerce-analysis.sql`
